# Source media

This directory contains original, editable, or reference material. It is intentionally separate from `public`, so large working files are not served by the website.

- `design-source/`: layered design files
- `documents/`: project decks and other references
- `images/architecture/`: original facility renders
- `images/brand/`: original logo exports
- `images/gallery/`: additional image candidates
- `images/mockups/`: full-page website mockups
- `images/screenshots/`: captured design references
- `images/misc/`: uncategorized source images
- `videos/`: original footage and video exports

Copy only web-ready, optimized assets into the matching folder under `public` when they are used by the application.
